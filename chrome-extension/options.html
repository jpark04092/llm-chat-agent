사내 LLM 웹 챗과 VS Code Agent를 연결할 때 발생하는 가장 흔한 문제는 "DOM에 텍스트를 넣어도 전송 버튼이 활성화되지 않거나 React 상태가 갱신되지 않는 현상"입니다.

1. React Input Value Tracker 해결법:
React 16+는 input.value = 'text'를 가로챕니다. 따라서 아래 프로토타입 세터를 호출해야 React가 변경을 감지합니다:
const setter = Object.getOwnPropertyDescriptor(window.HTMLTextAreaElement.prototype, 'value').set;
setter.call(textarea, text);
textarea.dispatchEvent(new Event('input', { bubbles: true }));
2. 원클릭 Element Picker:
웹 페이지 우측 하단에 뜨는 VS Code Agent HUD에서 [🎯 DOM 선택기]를 클릭한 후, 브라우저 화면의 입력창과 답변 박스를 클릭하면 자동으로 선택자가 등록됩니다!
