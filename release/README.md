# Release Artifacts
This folder contains the latest compiled VS Code extension `.vsix` packages generated automatically by GitHub Actions CI.

## Installation
1. Download or copy the `.vsix` file from this folder.
2. In VS Code, open the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`).
3. Click the `...` (More Actions) menu at the top right of the Extensions view.
4. Select **Install from VSIX...** and pick the `.vsix` file.
